# FlowStock WMS staging frontend

Browser assets for the FlowStock development/test environment. This repository contains only the desktop and handheld RF frontend; backend code and architecture documents remain in the private application repository.

- Desktop: https://abhishek7724.github.io/flowstock-wms-web/
- Handheld RF: https://abhishek7724.github.io/flowstock-wms-web/rf/

Sign in with an existing FlowStock staging account. Demo mode is disabled. Warehouse records are stored in Supabase and governed by backend access controls.

Published from private source revision 5fef6d20a89cee44f7c1eb0c5627594e77246bfc, frontend directory only. No private Git history is included. Updates must copy the reviewed frontend assets only; never copy backend files, credentials or data exports.

The browser publishable key is intentionally public. Database passwords and privileged backend keys must never be added here.
